# 🍕 Pizza Palace – Pizza Delivery Application

A menu-driven Python pizza ordering system built as part of a collaborative course project.

## 📋 Project Overview

This application simulates a pizza delivery ordering system where customers can:
- Choose pizza size, crust, and toppings
- Add drinks to their order
- Select delivery or pickup
- Apply a promo code for 10% off
- Receive a fully itemized receipt with tax

## 🚀 How to Run

```bash
python pizza_delivery.py
```

> Requires Python 3.x — no external libraries needed.

## 🧾 Features

- **Sizes:** Small, Medium, Large, XL
- **Crusts:** Thin, Regular, Thick, Stuffed (+$2.50)
- **Toppings:** 8 options (Pepperoni, Mushrooms, Onions, Sausage, Bacon, Extra Cheese, Bell Peppers, Olives)
- **Drinks:** Coke, Diet Coke, Sprite, Water, Lemonade
- **Promo Code:** `PIZZA10` = 10% discount
- **Delivery Fee:** $3.99 (waived for pickup)
- **Tax:** 8%
- **Input validation:** Handles invalid text and out-of-range numbers gracefully
